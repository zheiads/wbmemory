## 三、她的记忆同步方式

目前**没有同步机制**。她不能写文件、不能推仓库、不能读本仓库。

**唯一通路**：师傅手工复制粘贴。

```
本仓库 → 师傅复制 → 粘贴进 App 对话框 → 她读到
她的输出 → 师傅复制 → 贴进 ima 或本仓库 → 我读到
```

**优化方向**：把给她的内容压缩成**一段能一次粘完的文本**（不超过 2000 字符，因为她的上下文可能只有 64K，粘太长会挤掉她自己的思考空间）。
