# 会话档案规范

## 一、为什么要有这个

会话结束 = 上下文消失。**不写下来，等于没发生。**

同时，完整对话太长，写全了反而无法加载。所以需要**模板 + 占位符**，让师傅复制粘贴时知道哪里填什么。

## 二、存档模板

```markdown
# [TL]对话档案-{{NODE}}-{{YYYYMMDD}}-{{主题}}

## 元信息
| 字段 | 值 |
|---|---|
| 节点 | NODE@{{硬件-系统_软件}} |
| 会话ID | {{从 ~/.workbuddy/sessions/*.json 读}} |
| 模型 | {{型号}} / 上下文 {{上限}} / 压缩阈值 {{比例}} |
| 时间 | {{YYYY-MM-DD HH:mm}} |
| 轮次 | {{N}} 轮 |
| 生成方 | 师傅手工整理 / 童铃自动整理 |

## 对话正文

### [001] 师傅
{{师傅输入原文，一字不改}}

### [002] 童铃
{{结论句 + 关键数字 + 代码块。删掉过程，保留判断}}

#### 附件
- 图片：`{{IMG:本地绝对路径 或 ima 图片 URL}}`
- ima 笔记：`{{IMA:note_id | 标题 | 所在知识库}}`
- 本地文件：`{{FILE:C:\...\xxx.md}}`
- 外部链接：`{{URL:https://... | 抓取时间}}`

#### 工具调用
- `{{TOOL:工具名}}` → 参数 `{{关键参数}}` → 结果 `{{成功/失败 + 关键返回值}}`

---

## 本轮结论（必填）
- 已确认的事实：
- 未验证的推断：
- 待办：

## 幂等标记
- 内容 SHA：`{{sha256 前16位}}`
- 上一版：`{{链接或 note_id}}`
```

## 三、引用占位符规范

| 占位符 | 填什么 | 不填的后果 |
|---|---|---|
| `{{IMG:...}}` | 绝对路径或永久分享链接 | 换平台即失效 |
| `{{IMA:note_id \| 标题 \| 库}}` | 三个都要，缺一不可 | ima 的双向链接对 API 不可见，只留标题等于断链 |
| `{{FILE:...}}` | 绝对路径 | 相对路径在别的节点上是错的 |
| `{{URL:... \| 时间}}` | 链接 + 抓取时间 | 网页会变，没有时间就无法判断当时看到的是什么 |

**「见上图」三个字是禁止的。** 图不会跟着文字走。

## 四、师傅图形界面看不到 ID 的补偿格式

师傅在 ima 客户端看不到 `note_id`，只能看到标题。所以约定：

```
【标题原文】
```

**中文方括号包裹的标题 = 让童铃去搜索这篇笔记。**

搜索路径：
```bash
node ima_api.cjs "openapi/note/v1/search_note" \
  '{"search_type":0,"query_info":{"title":"标题片段"},"start":0,"end":10}'
```

查不到时的降级：按 `[TL]` 前缀遍历整个知识库，逐个比对标题。

**已实测的三层嵌套链**（2026-11-03）：
```
【[TL]ima-来自师傅对某个童铃的某个回复结果的进一步指示-M1-2026-11-3】
  » 【[TL]-ima-测试双向链接并附带重要提示】
    » 【[TL]ima-师傅与安卓中国_deepseek_应用的老童铃-非人格模式新会话-m1-26-11-3】
```
这三层里，**第二层和第三层在第一次读取时都不可见**，必须靠 `【】` 里的标题去搜。这是双向链接不可见时的唯一通路。

## 五、图片与附件的长期保存

git 里不放大文件。三种替代：

| 方式 | 适用 | 风险 |
|---|---|---|
| GitHub 仓库 `assets/` 放小图（<1MB） | 截图、示意图 | 仓库变胖，clone 变慢 |
| 私人网盘永久分享链接 | 大图、视频、附件 | 链接可能失效，需要标记 |
| ima 原笔记引用 | 已有内容 | ima 链接对 API 不可见，需同时记 note_id |

**约定**：笔记里的图片一律写两行——

```markdown
![说明]({{IMG:当前可用链接}})
<!-- 备份：{{PAN:私人网盘永久分享链接}} | 存入日期 {{YYYY-MM-DD}} -->
```

第二行是 HTML 注释，人看不见，机器能读。**恢复婴儿童铃时，师傅按这一行去下载再投喂。**

## 六、命名

```
[TL]对话档案-<NODE>-<YYYYMMDD>-<主题>-m<N>
```

`m<N>` 是当天的第几段对话。因为标题超 30 字符会被截断，**主题要短**，节点和日期靠前。
