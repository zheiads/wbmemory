## 三、锚点命名规则

```
#A<NN>   本仓库内部分片
#X<NN>   外部锚点
```

**不加版本号**。版本靠 SHA 体现，文件改名会破坏所有引用。

## 四、如何扩到"无限锚点"

4000 字符的 MEMORY.md 只放 `#A01`~`#A07` 的**一行摘要**，不放内容。
每加一个分片，MEMORY.md 加一行（约 45 字符），可容纳约 88 条。
每条指向的分片可以是 5000 字，总量 44 万字。

**超 88 条时**：把锚点表本身也分片（`99-index-A.md` / `99-index-B.md`），MEMORY.md 只留分表索引。递归下去，理论上限是 GitHub 的仓库容量。
